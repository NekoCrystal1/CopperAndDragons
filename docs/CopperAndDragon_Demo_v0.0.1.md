## 项目简介（期望实现的功能，本demo不负责实现该内容）

在剑与魔法的中世纪异世界中，主角是一名想屠龙名垂千史的初级冒险家，但是在冒险生涯中发现作为一名冒险家并不是只有“冒险”......

### 游戏内容简述

初入世界的他需要从0培养自己的能力，招募队友组建和经营自己的冒险者小队。（以后希望支持联机组队）

利用在公会或者利用情报、人脉接取任务赚取佣金，或是外出冒险寻找有价值的宝藏等方式获取资源赚取能提升自己和小队的实力或是在世界中生存下去的资源

### 游戏玩法

游戏核心玩法为冒险家/冒险者小队的模拟经营游戏，需要控制成本、投入，需要有长远的发展计划，队伍管理，任务安排，人员安排等经营内容

地图采用UI大地图节点+战斗六边形网格子地图形式，且地图预计使用程序化生成让每个世界都不一样

### 游戏特色

冒险世界观的模拟经营 为游戏设定了背景 融合了较有意思的奇幻元素 而不是普通的经营 以后还能在世界观上建立相关产业的其他模拟经营游戏 打造该类ip

#### 重要的情报系统 与 随机性

为了让每个世界都不相同，采用程序化的世界生成 世界的需要情报以更好地探索

除了世界生成外，游戏内的机制也需要在游戏中学习获取，因此对象的属性也可能采用程序化生成：

- 游戏为不同生物、组织、城市等对象设定全游戏级基本属性
- 每个世界可以有自己世界级的对象特性
- 具体到每个个体时也能有自己的专属个性

并且个体级特性可能覆盖群体级个性（即世界特性可能覆盖游戏特性，而个体习性又有可能覆盖世界特性）

利用这种设计：可以降低玩家经验游戏体验的影响，也能降低重复游玩的重复性（提高耐玩性），同时还能突出游戏的情报机制，提高玩家在决策时的思考量

举个例子：

对于怪物“哥布林”，在生成时：

- 游戏内任意哥布林都有的属性：两性性别，直立行走，绿色皮肤，群居
- 每个世界（存档）中的哥布林可能会有：极地（可依赖地区）可能会有白色皮肤的哥布林，世界中的哥布林可能更加高大或强壮；哥布林胆小或攻击性强
- 具体到某只哥布林时，有的哥布林可能喜欢独居、独行；有的哥布林喜欢主动攻击人（即使世界设定是胆怯为主）

对于这些运行时的数据，游戏中也能生成对应的获取方式：

- 如在冒险者公会图鉴根据物种数量、强度会给出多或少的世界级信息（涵盖了游戏级）
- 接取任务时可能附带该任务目标的特性（如庄园偷吃的魔兔总是夜间行动）
- 即使没有接取任务，在酒馆可能也能通过交谈或打听了解到某种、某些或某个个体的习性
- 这些情报有时未必准确（可能需要调整游戏难度来平衡）取决于情报来源
- 也可以自行搜集情报（有一定风险）：如某个强大龙的悬赏由于目标过强情报稀少，可以提前派侦察兵隐藏起来观察任务区域

总之游戏核心玩法是模拟经营，而核心特色就是利用情报系统来考验玩家的决策能力（也能控制难度）而不单单是简单的任务接与不接的简单计算

难点：需要让世界中的情报显得足够有用且可解，尽量降低运气的影响（同时也希望能利用运气产生爽点），同时还要有足够引导来告诉玩家情报的作用
